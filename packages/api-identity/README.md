## Install

```bash
npm install @autional/core @autional/api-identity
```

## Quick Start

```ts
import { Autional, browserPlatform } from '@autional/core';
import { getDevices } from '@autional/api-identity';

const autional = new Autional({
  appId: 'my-app',
  issuer: 'https://auth.example.com', // your Autional server URL
  platform: browserPlatform,
});
await autional.initialize();

// 返回值已由 ApiClient 解包为载荷（不是 { code, data, message } 信封）
const result = await getDevices(autional.api);
console.log(result);
```

## Conventions

- Every function takes the `ApiClient` as its first argument (`autional.api`).
- Field names convert automatically: `camelCase` at the call site, `snake_case` on the wire.
- Return values are unwrapped payloads, not `{ code, data, message }` envelopes.

See the [root SDK README](../../README.md) for tokens, refresh, and OAuth flows.
